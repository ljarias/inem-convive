# Control de publicación | INEM Convive v0.2.2

- Destino: `ljarias/inem-convive`, rama `main`, GitHub Pages desde `/ (root)`.
- URL: `https://ljarias.github.io/inem-convive/` (solo cuando responda HTTP 200 y la marca de versión sea `0.2.2-publica-github-pages`).
- Fuente de los casos: Manual de Convivencia institucional proporcionado para el piloto; PDF excluido deliberadamente.
- Los 30 casos son ficticios, la aplicación no recibe denuncias, nombres ni datos de estudiantes.
- El PDF debe seleccionarlo cada usuario desde su dispositivo, sin subida a servidores.
- Las verificaciones del paquete prueban integridad estructural y sintaxis, no accesibilidad WCAG 2.2 AA ni compatibilidad móvil física.
- El escudo institucional se usa en el contexto de la demostración solicitada. Revisar su autorización pública antes de tratar el sitio como producto oficial.
- La cuenta y el estado de Pages se verifican localmente mediante la GitHub CLI autenticada; sin esa autenticación no es posible finalizar desde esta conversación.
