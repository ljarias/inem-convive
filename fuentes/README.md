# Fuente del contenido

Los casos educativos de INEM Convive se basan en el Manual de Convivencia de la IEDT INEM Simón Bolívar suministrado para el piloto.

**El PDF institucional no está incluido en esta distribución pública** mientras se confirma la autorización de redistribución.

El usuario puede seleccionar desde la propia página una copia local legítimamente obtenida del PDF. Se abre dentro del navegador, no se transmite, almacena ni publica. El número de página mostrado en cada ejercicio se refiere al PDF fuente de 134 páginas utilizado para crear el piloto; ediciones posteriores pueden diferir.
